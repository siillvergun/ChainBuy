# ChainBuy · blockchain

공동구매 예치·결제·환불·수수료 규칙을 강제하는 스마트컨트랙트입니다. 노션 요구사항 명세서 v0.2의 5장을 구현합니다.

## 실행

```bash
npm install
npm test            # 전체 테스트
npm run coverage    # 커버리지
```

로컬 체인에 배포:

```bash
npm run node                 # 터미널 1: 로컬 블록체인
npm run deploy:local         # 터미널 2: 배포 → deployments/localhost.json
```

## 컨트랙트

| 파일 | 설명 |
| --- | --- |
| `contracts/ChainBuy.sol` | 공구 전체를 `id`로 관리하는 에스크로 |
| `contracts/ChainBuyUSD.sol` | 테스트 토큰 (소수점 6자리, 누구나 발행) |

### 역할

| 역할 | 할 수 있는 일 |
| --- | --- |
| `DEFAULT_ADMIN_ROLE` | 역할 관리, 허용 쇼핑몰 등록, 수수료율(≤10%)·수령 주소 변경, 긴급 정지 |
| `REVIEWER_ROLE` (담당자) | 판매자 등록, 외부 상품 공구 생성, 결제 승인·거절, 이의 처리 |
| `AGENT_ROLE` (AI) | 확인 결과 제출, 경로 A 결제·경로 B 카드 충전, 주문 증거·배송 기록 |

### 상태 흐름

```
OPEN ──(미달)──▶ FAILED ─▶ 환불
  │(목표 달성)
  ▼
PENDING_CHECK ──(초과·품절·거절·7일 경과)──▶ CANCELLED ─▶ 환불
  │ submitCheck + approve
  ▼
APPROVED ─▶ PAID ─▶ SHIPPED ──(수령 확인 / 7일)──▶ COMPLETED
```

### 돈 계산 (수수료 5%)

| | 입점 상품 (판매자 부담) | 외부 상품 (구매자 부담) |
| --- | --- | --- |
| 1개당 예치 | 최대 가격 | 최대 가격 + 수수료(올림) |
| 결제 | 판매자 지갑에 (실제 가격 × 수량 − 수수료) | 카드 충전 주소에 한도 내 금액, 잔액 반환 |
| 수수료 | 실제 결제 금액의 5%, 컨트랙트에 보관 후 참여자별 지급 | 같음 |
| 차액 환불 | 예치 − 실제 상품 금액 | 예치 − 실제 상품 금액 − 수수료 |

## 테스트 구성

| 파일 | 내용 |
| --- | --- |
| `01.open.test.ts` | 생성·예치·취소·마감·미달 환불 |
| `02.approve.test.ts` | AI 확인·승인·거절·승인 기한 취소 |
| `03.payment.test.ts` | 경로 A·B 결제, 잔액 반환, 차액 환불, 반올림 |
| `04.settle.test.ts` | 주문 증거·배송·수령 확인·이의·수수료 지급 |
| `05.attack.test.ts` | 결제 대상 조작·2회 결제·권한 없는 호출·관리자·긴급 정지 |

## 알려진 한계

- 경로 B에서 카드 발급사가 잔액을 반환하지 않으면 차액 환불과 배송 기록이 진행되지 않습니다 (카드 발급사를 신뢰하는 전제).
- 외부 상품의 1인 몫은 올림으로 계산해, 아주 작은 단위의 잔액(참여자 수 이하)이 컨트랙트에 남을 수 있습니다.
